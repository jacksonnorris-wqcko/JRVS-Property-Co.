## FlashRaw

JRVS Desktop bundles the FlashRaw JavaScript/WebAssembly RAW decoder from the pinned npm package `flashraw@0.1.0`.

Project: https://github.com/ybouane/flashraw
Package: https://www.npmjs.com/package/flashraw
License: dual-licensed MIT OR Apache-2.0.

The desktop frontend includes the FlashRaw browser module and WebAssembly runtime under `desktop-dist/vendor/flashraw/`. The corresponding upstream `LICENSE-MIT` and `LICENSE-APACHE` files are copied into that same folder and distributed with the desktop application. FlashRaw no longer needs a runtime CDN download in the desktop build.
