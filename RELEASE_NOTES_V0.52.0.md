# JRVS Property Co. Desktop — V0.52.0 Release Notes

## Interface and readability
- Removed the persistent desktop status strip at the bottom of every page and reclaimed that space for the workspace.
- Reworked desktop surfaces around charcoal, deep green and muted sage tones. Pale cream panels are replaced with darker surfaces and higher-contrast text while preserving the JRVS logo and brand identity.
- Improved the Pricing & Quotes package cards with clearer hierarchy, more readable descriptions, stronger price visibility and expandable inclusion lists.

## Quotes and packages
- Reworked package selection in the quote form to resolve the selected package directly from the current package records.
- Selecting a package now applies its current price, including a valid zero price, and recalculates quote totals.
- Saved quote items retain their package name and link where available, including when an older quote refers to a package that has since been removed.
- Existing saved quote prices are preserved when editing a quote until the user changes the selected package.

## Desktop workspace
- Updated the sidebar workspace status so it accurately describes local records, managed photo copies and portable backups.
- No business-data schema or backup format migration is introduced in this release.
