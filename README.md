# JRVS Property Co. — V0.0.6.1 Beta

## Quote page polish
- Summary cards now use clear labels with punctuation and consistent spacing.
- Cleaner quote cards show linked client, linked job, quote date, amount and status.
- Quote cards include direct View client and View job actions when linked records exist.
- Job selector is filtered to the selected client (plus unassigned jobs) to prevent accidental mismatches.
- Existing quote, package, client, job and photo data is preserved.

## Install
Upload all files in this ZIP to the root of the existing GitHub Pages repository, replacing the previous files. Keep the same browser profile and device. Automatic update metadata and service worker cache are updated to V0.0.6.1.

## Note
Quotes and packages are stored locally in this browser. Finance tracking, PDF generation and cloud sync are not included in this release.
