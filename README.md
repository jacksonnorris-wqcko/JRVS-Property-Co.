# JRVS Property Co. — V0.1.3 Beta

## Dashboard improvements
- Refined spacing, cards, hover/focus states and responsive layout.
- Recent jobs are now full clickable project cards; selecting one opens its Job Overview.
- Recent project cards show client, date, status, photo count, income received and outstanding amount.
- Displays the project's cover photo when available, otherwise a neutral placeholder.
- Recent jobs sorted by scheduled date (newest first).

## Job Overview improvements
- Added a Project photos section showing up to 12 thumbnails.
- Thumbnails open the existing photo preview.
- Added a shortcut to open the project's full gallery.

## Install
Upload all files in this ZIP to the root of the existing GitHub Pages repository, replacing previous files. Continue using the same browser/device to retain local records and photos.

## Baseline
Builds on JRVS V0.1.2. Existing localStorage keys and IndexedDB photo database are unchanged.
