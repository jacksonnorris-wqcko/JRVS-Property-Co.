# JRVS Property Co. — V0.1.1 Beta

## Fixes
- Dashboard Needs attention now refreshes immediately when a quote is created, edited or its status changes.
- Draft quotes appear as "Quote ready to send"; Sent quotes appear as "Quote awaiting client response".
- Quote job/property selector now filters to jobs belonging to the selected client.
- Changing the client in the quote form immediately refreshes the available jobs.
- Editing an existing quote preserves its selected job when it belongs to the selected client.

## Install
Upload all files in this ZIP to the root of the existing GitHub Pages repository, replacing previous files. Continue using the same browser/device to retain local records and photos.

## Baseline
V0.1.1 builds on the JRVS V0.1.0 baseline. Existing localStorage keys and IndexedDB photo storage are unchanged.
