# JRVS Property Co. — V0.0.8 Beta

## What's new
- Replaced browser alert job details with a structured in-app Job Overview modal.
- Clear property and client information cards.
- Financial summary for income received, outstanding income and expenses.
- Dedicated linked income and expense lists with edit actions.
- Linked quotations with edit actions.
- Job notes displayed in a readable notes panel.
- Responsive layout for desktop and smaller screens.
- Corrected visible app version labels to 0.0.8.

## Install
Upload all files in this ZIP to the root of the existing GitHub Pages repository, replacing the previous files. Keep using the same browser profile/device to retain local records and photos.

## Storage
This release does not change the localStorage data key or IndexedDB photo database.
