# JRVS Property Co. V0.2.0

Mobile compatibility release built on V0.1.9.7.

- Desktop layout and existing workflows retained.
- iPhone responsive layout with two-row bottom navigation.
- iOS safe-area and standalone web-app metadata.
- Touch-friendly controls, form sizing and bottom-sheet modals.
- Mobile-optimised photo library, calendar, finance and photo editor layouts.
- Existing localStorage keys and IndexedDB photo library are preserved.

## Deploy
Extract the ZIP and upload all files and folders into the existing GitHub Pages repository root, replacing matching files. Do not clear browser data. On iPhone, open the site in Safari, tap Share, then Add to Home Screen.
