# JRVS Property Co. — V0.1.2 Beta

## Dashboard quote shortcut
- Selecting Edit quote from Needs attention opens that exact quotation directly in the quote edit modal.
- The user stays on the Dashboard; no navigation to Pricing & Quotes is required.
- Saving the quote updates the dashboard attention list.
- Changing quote status also refreshes the attention list immediately.

## Install
Upload all files in this ZIP to the root of the existing GitHub Pages repository, replacing the previous files. Continue using the same browser/device to retain local records and photos.

## Baseline
Builds on JRVS V0.1.1 / V0.1.0 baseline. Existing localStorage keys and IndexedDB photo storage are unchanged.
