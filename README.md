# JRVS Property Co. V0.1.5.8
Pricing workspace usability refinement.

- Moved Create a quote into the Quotations section header.
- Refined Packages / Quotations / Invoices switcher into a clean segmented control with count badges.
- Each section shows only its four most recent matching records by default.
- Search checks all records, including older ones, and supports client names, company/email, property/job names and addresses, plus document numbers and relevant fields.
- Packages can be searched by package name, description and price.
- Existing quote/invoice status filters remain available.
- Existing localStorage and photo IndexedDB data are preserved; no migration or reset.
- Based on V0.1.5.7.
